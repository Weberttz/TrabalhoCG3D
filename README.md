# TrabalhoCG3D

## Como executar
```bash
# instala npm
npm install
# inicia o servidor
npm start 
```

Com o servidor aberto, abra o navegador e entre em http://localhost:3000

### Conectividade de mais de um jogador

```bash
hostname -I
ip addr
```
Encontre o ip local da máquina que esta hosteando o servidor, entre no navegador da outra máquina e pesquise por:
http://<ip_privado>:3000
